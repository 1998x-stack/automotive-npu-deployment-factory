# Experiment 02 — measured FP16, head-only QAT and paired robustness

Execution: 2026-10-28 | [successful GitHub Actions run](https://github.com/1998x-stack/automotive-npu-deployment-factory/actions/runs/40668420358) | artifacts: experiment02-fp16-qat-statistics.

## What was actually executed

- Pretrained MobileNetV2, ImageNet1K_V2 weights; 1000-way classifier evaluated on real Imagenette-160 (10 selected ImageNet categories).
- GitHub hosted x86 Ubuntu CPU, Python 3.11.17, torch 2.14.1+cpu.
- 240 calibration images from Imagenette train, 100 validation images, 350 held-out test images (all disjoint).
- Original FP32 ONNX; FP16 internal ONNX conversion; static QDQ INT8 PTQ using selected 64-calibration-image MinMax/per-channel recipe.
- Head-only FakeQuantize QAT (quint8 activation and qint8 per-output-channel weights), *pretrained FP32 backbone frozen*. Matched FP32 fine-tuned head used same features, optimizer, training split and epochs.
- Training seeds 7,19,31; seed selected by validation Top-1 before test, final QAT seed 19.
- 5000 image-paired bootstrap samples per comparison, 95% percentile confidence intervals, exact two-sided McNemar p.

## Important limitations

1. **No SA8255P/SA8295P hardware, HTP profiler, QAIRT Context Binary or DSP logs**: this is CPU/numerical validation only.
2. **QAT covers only the last classifier head**, not the backbone. The QAT head is a fake-quant simulation inside a larger FP32 model and is not a directly deployable full-INT8 ONNX or QNN artifact.
3. FP16 ONNX checker and CPU execution do not prove that a device executes arithmetic in hardware FP16 or that it is faster.
4. This is a ten-class Imagenette distribution with 350 holdout images, not the full ImageNet or real in-cabin domain. Paired confidence intervals condition on these images.
5. A QAT accuracy increase relative to original pretrained FP32 is **not** evidence of QAT benefit because matched FP32 fine-tuning improved equally.
6. Three seeds assess a narrow source of training variability; larger validation/test sets, a full-model QAT baseline and real NPU benchmarks remain necessary.
